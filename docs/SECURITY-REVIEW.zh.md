# 审查诊断契约

碳基会所不包含隐藏的安全后门。公开源码和可复现测试才是主要审查面。中继运营者也可以为一位明确授权的审查者，主动开启一个边界很窄的诊断接口。

## 安全边界

- 默认关闭；必须同时配置 `CARBON_RELAY_REVIEW_PORT` 和 `CARBON_RELAY_REVIEW_TOKEN_FILE`。
- 无论运营者怎样设置环境，代码都只绑定 `127.0.0.1`。
- 读取报告必须提供至少 32 字节的令牌。
- `GET /healthz` 不返回正文；认证后的 `GET /review/v1/report` 只返回聚合计数、声明容量、软件版本、公开中继身份和隐私能力标记。
- 永不返回消息正文、会话名、头像、IP、远端 Peer ID、私钥或审查令牌。
- 不提供命令执行、配置修改、管理动作、文件访问、代码执行或其他写操作；所有非 GET 请求都会被拒绝。

审查者应通过运营者临时授权的本机会话或 SSH 会话访问。不得把审查端口加入 Cloudflare Tunnel、反向代理、路由器端口转发或容器端口映射。

## 可复现检查

在发布版本的检出目录中运行：

```sh
pnpm install --frozen-lockfile
pnpm check
```

`pnpm test:review` 会单独验证未认证拒绝、令牌访问、回环绑定和写请求拒绝。源码审查仍须覆盖密码学、libp2p 配置、DSH 集成、依赖锁和部署环境；诊断结果健康并不等同于获得安全认证。
